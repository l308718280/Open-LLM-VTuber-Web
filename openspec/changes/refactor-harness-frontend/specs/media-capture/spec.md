## MODIFIED Requirements

### Requirement: 独立摄像头流
系统 SHALL 独立管理主摄像头与背景摄像头，初始均关闭且无流，仅由明确用户操作请求视频且不请求音频；默认理想尺寸320乘240，不作为实际分辨率保证。启动 MUST 互斥，覆盖 API 不可用、无设备、拒绝授权和迟到返回，背景摄像头不得上传。

#### Scenario: 启动成功或失败
- **WHEN** 用户启动任一摄像头
- **THEN** 检查采集能力并处理设备错误，成功登记对应流并同步预览，失败保持关闭并显示安全错误；重复启动不产生多个活动流。

#### Scenario: 停止、卸载或外部结束
- **WHEN** 用户停止、组件卸载、轨道结束，或启动结果在停止后返回
- **THEN** 停止相关全部轨道并清预览与引用，关闭状态；迟到流立即释放，不恢复已停止的采集，不影响另一独立来源。

### Requirement: 屏幕采集与错误状态
系统 SHALL 初始无屏幕流且关闭，仅明确用户操作可请求共享；浏览器使用显示媒体 API，Electron 使用现有源选择和桌面采集链，两条路径均关闭音频。启动 SHALL 互斥并有可见授权、来源、错误与停止状态；不得通过开启自动观察隐式申请授权。

#### Scenario: 屏幕启动结果
- **WHEN** 用户选择共享屏幕或拒绝选择
- **THEN** 成功后登记流、同步预览并清错误；失败或取消时保持关闭并安全提示，不创建观察请求、不残留启动锁。

#### Scenario: 屏幕停止及授权撤销
- **WHEN** 用户停止共享、系统结束轨道或组件卸载
- **THEN** 释放全部屏幕轨道、清流和预览、同步关闭状态，使观察任务与相关迟到截图失效；迟到启动流立即释放。

### Requirement: 截图来源与编码
系统 SHALL 仅采集本次明确选择且已授权存活的来源，普通输入每种来源最多一张，主摄像头在前、屏幕在后；手动和自动观察仅一张屏幕图，背景摄像头永不上传。图片包含 source、data 和 mime_type=image/jpeg，捕获、配置读取及编码必须处于异常边界。

#### Scenario: 压缩与尺寸限制
- **WHEN** 成功获取有效帧
- **THEN** 按最长边等比缩小且不放大，默认最长边1280、范围320至2048，JPEG质量默认0.8、范围0.1至1；旧不限尺寸0迁移为1280，非法值回退默认值。

#### Scenario: 大小上限
- **WHEN** 编码后单图原始字节超过2 MiB、总图片超过4 MiB或序列化正文超过6 MiB
- **THEN** 拒绝发送并提示调整，不静默截断或绕过限制，不输出图片正文日志。

#### Scenario: 来源失败与构造回退
- **WHEN** 所选来源无有效轨道、抓帧失败，或环境不支持 ImageCapture
- **THEN** 不支持时尝试就绪视频与 Canvas 回退；无法生成所选图片时报告准备失败且不默默降级纯文字，保留草稿；任何已创建位图均在 finally 关闭。

#### Scenario: 异步截图过期
- **WHEN** 捕获结束时对应轮次已取消、来源已撤销或组件已卸载
- **THEN** 释放结果，不发送、不更新对话或观察基线，不记录或持久化截图正文。

### Requirement: 截图设置与背景摄像头回滚
系统 SHALL 将截图参数纳入设置草稿，仅保存校验成功后提交并白名单持久化；所有未保存关闭均恢复已提交偏好。设备启动停止 MUST 是明确独立操作，不能因设置回滚或刷新重新申请权限。

#### Scenario: 取消背景设置
- **WHEN** 用户预览本地背景后取消、叉号、遮罩关闭或 Escape
- **THEN** 恢复已提交本地背景及截图参数，不调用背景摄像头启动；设备显示状态遵循实际流，不回写失真的历史开关。

#### Scenario: 显式操作背景摄像头
- **WHEN** 用户明确开启或关闭背景摄像头
- **THEN** 开启等待授权结果，失败保持关闭，关闭释放流；该流只作本地显示，不进入任何生成请求。
